# Guided example engagements

End-to-end walkthroughs that show what a successful LazyOwn session looks
like, command by command, with the outputs you should expect. Use them to
learn the golden path before your first live engagement.

| Walkthrough | Target | Covers |
|-------------|--------|--------|
| [htb-lame-walkthrough.md](htb-lame-walkthrough.md) | HackTheBox **Lame** (retired, Linux) | wizard, golden path, SMB enum, exploit, shell, loot |

Conventions used in every walkthrough:

- `(LazyOwn) >` is the interactive shell prompt; `$` is your OS shell.
- Outputs are abridged — real scans produce more lines.
- Targets are retired lab machines. Never point these techniques at
  systems you do not own or lack written authorization to test.
