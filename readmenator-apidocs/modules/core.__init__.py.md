# `core`

> Source: [core/__init__.py:1](../../core/__init__.py#L1) | language `py` | coverage 100.0% | [API index](../index.md)

Core primitives for the LazyOwn framework.

Stable, dependency-light building blocks shared by the CLI (``lazyown.py``),
the C2 (``lazyc2.py``), the MCP server (``skills/lazyown_mcp.py``) and the
autonomous skill stack. ``utils.py`` re-exports these symbols for backwards
compatibility with legacy import paths.
